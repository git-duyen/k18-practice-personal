1.Git 
1.1 : Git undo : restore from staging to Working Directory
Câu lệnh :
git restore --stage <filename> : restore 1 file cụ thể
git restore --stage . : restore toàn bộ file 
1.2 : Git un-commit : restore from Repository to staging
Câu lệnh :
git reset HEAD~n (n là số commit)
để chính xác commit nào muốn reset : chạy git log 
1.3 : Pull code
git pull origin main : pull code từ serve về
xem danh sách nhánh : git branch
tạo nhánh : git branch <tên nhánh>
chuyển sang nhánh mới : git checkout <tên nhánh> 
chuyển sang nhánh mới vừa tạo : git checkout -b <tên nhánh>
xóa nhánh (phải đứng ở nhánh khác trước khi xóa) git branch -D <tên nhánh>
1.4 : Ignore 
file .gitignore
dùng để bỏ qua các file không cần git theo dõi

2.2 : Console.log : để in ra, để debug
console.log ('')
console.log (");
console.log (`${variablename}`);
ví dụ : 
let myName ="Thao";
console.log (`${myName}); => in ra Thao
Ngoài ra có thể in thêm chữ + tên biến
console.log ("My name is" + myName + "");

2.3 : object : là 1 đối tượng , hiểu đơn giản để lưu trữ dữ liệu dạng key-value, những value này có chung 1 hằng số hoặc biến 
cú pháp 
const/let <tên biến> = {
    key1 : value1,
    key2 : value2,
} 
<key> : quy tắc đặt tên giống tên biến
<value>: có thể là biến or object khác
Logical operator : 
&& : cả 2 vế đúng
|| : một trong 2 vế đúng
! : đảo ngược lại giá trị của mệnh đề
2.4 : mảng 
- Tạo mảng 
let numbers = [1, 2, 3, 4];
let names = ["An", "Bình", "Chi"];
let mixed = [1, "abc", true];
- Truy cập mảng
let arr = ["a", "b", "c"];

console.log(arr[0]); // "a"
console.log(arr[1]); // "b"
console.log(arr[2]); // "c"
- Độ dài mảng : 
console.log(arr.length); // số phần tử trong mảng
- Lấy phần tử theo index
let students = [
  { name: "An", score: 8 },
  { name: "Bình", score: 6 }
];
console.log(students[0].name); // "An"
console.log(students[1].score); // 6

- Thêm phần tử của mảng : dùng hàm push
const arr = [1,2];

{
    for(let i =0; i<=n, i++)
