Giải thích câu lệnh

git clone <url> : Clone một repo về máy

git branch <branch_name> : tạo nhánh mới 

git checkout <branch_name> : checkout sang nhánh đã có

git checkout -b <branch_name> : tạo + checkout sang nhánh mới

git pull origin master: lấy toàn bộ code từ nhánh master về, gộp các commit đó vào nhánh hiện đang đứng
