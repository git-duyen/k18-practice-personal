a. git clone <url>:  
Clone repository cụ thể theo url trên GitHub về máy.

b. git branch <branch_name>:  
Tạo 1 nhánh mới với tên <branch_name> từ nhánh hiện tại.

c. git checkout <branch_name>:  
Switch qua nhánh <branch_name> từ nhánh hiện tại.

d. git checkout -b <branch_name>:  
Tạo nhánh mới với tên <branch_name> và đồng thời switch qua nhánh mới này
 
e. git pull origin master:  
Lấy code mới nhất từ nhánh master trên GitHub về máy cá nhân
