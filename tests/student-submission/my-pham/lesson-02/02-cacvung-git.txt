- Vùng working directory: chưa có file
- Vùng stagging: chưa có file
- Vùng repostory: chưa có file

- Vùng working directory: có 3 file là file1, file2, file3
- Vùng stagging: chưa có file
- Vùng repostory: chưa có file

- Vùng stagging: chưa có file
- Vùng repostory: có version tên là 'init project' không gồm file nào
