# Lesson 6:
### Git
- git clone: là hành động lấy code từ 1 repo đã có sẵn về máy tính cá nhân
- git clone <link repo> <tên mới>: đặt lại tên cho thư mục
- git push: đưa code từ vùdng repo ở local của 1 nhánh cụ thể len trên remote. Câu lệnh: git push <remote_name> <branch_name>
- git pull: lấy code từ 1 nhánh cụ thể vè nhánh local
- git stash: lưu trữ thay đổi hiện tại vào bộ nhớ tạm
- git stash pop: dùng để lấy các lưu trữ
- git stash save "Tên": dùng để lưu và dễ gợi ý
