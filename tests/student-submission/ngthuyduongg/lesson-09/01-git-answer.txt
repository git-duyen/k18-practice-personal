a. Giải thích câu lệnh git rebase main, git merge feature/A

- git rebase main: thay đổi base (gốc) của branch hiện tại sang commit mới nhất của main
- git merge feature/A: gộp nội dung của nhánh feature/A vào nhánh đang đứng hiện tại

b. Giải thích các merge strategy: fast-forward, three way merge. Khi nào thì các strategy này xảy ra?

1. fast-forward: 
- Khi merge không tạo tạo ra commit merge
- Xảy ra khi không có thay đổi nào trên nhánh chính kể từ lúc tạo nhánh feature

2. three way merge
- Khi merge có tạo ra commit merge
- Xảy ra khi bạn muốn merge feature branch vào branch chính mà lịch sử của 2 branch này có sự khác nhau
